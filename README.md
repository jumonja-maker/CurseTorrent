# CurseTorrent

Классический торрент-клиент для **Windows 11 x64** с русским интерфейсом: `.torrent`, magnet-ссылки, скачивание и раздача, управление файлами и скоростью. Минималистичный тёмный интерфейс, без рекламы и учётной записи.

**Версия 0.1.0 — предварительная.** Движок — [MonoTorrent 3.0.2](https://github.com/alanmcgovern/monotorrent/tree/release-v3.0.2), интерфейс — WPF, среда выполнения — .NET 10.

## Скачать и запустить

1. Откройте [Releases](https://github.com/jumonja-maker/CurseTorrent/releases).
2. В последней предварительной сборке скачайте **`CurseTorrent-win-x64.zip`**.
3. Полностью распакуйте архив в отдельную папку, например `D:\Programs\CurseTorrent`.
4. Запустите **`CurseTorrent.exe`** из распакованной папки.

Среда .NET уже входит в архив. Файлы рядом с `.exe` нужны для работы; переносите всю папку целиком. Сборка пока не имеет цифровой подписи издателя, поэтому Windows может показать предупреждение о неизвестном издателе.

Для необязательной установки в профиль пользователя запустите **`install.cmd`**. Он скопирует программу в `%LOCALAPPDATA%\Programs\CurseTorrent` и добавит ярлык в меню «Пуск». Права администратора не требуются. Папку для скачиваемых файлов можно выбрать отдельно в приложении.

Готовый архив публикуется после успешной проверки ядра на Linux и Windows, запуска нативного интерфейса и проверки установки/удаления. У каждой сборки есть SHA-256, журналы проверок и настоящий снимок окна.

## Возможности

| Действие | Как работает |
| --- | --- |
| Открыть `.torrent` | Кнопка «＋ Торрент», `Ctrl+O`, перетаскивание файла или Проводник после регистрации |
| Добавить magnet | Кнопка «Magnet» или `Ctrl+M`; папка выбирается до добавления |
| Выбрать файлы | В окне добавления `.torrent`; после добавления — во вкладке «Файлы» |
| Изменить приоритет | Пропустить, низкий, обычный или высокий приоритет отдельного файла |
| Управлять задачей | Пауза, продолжение, повторная проверка целостности, удаление из списка |
| Следить за загрузкой | Прогресс, скорости приёма/отдачи, пиры, оценка оставшегося времени |
| Найти задачу | Поиск по названию и фильтры скачивания, раздачи, паузы и ошибок |
| Настроить соединения | Общие ограничения скоростей, порт, число соединений, необязательный UPnP/NAT-PMP |
| Продолжить позже | Сохранение списка, папок, приоритетов и состояния задач |
| Работать в фоне | Системный трей с восстановлением окна и выходом |

У magnet-ссылки список файлов появляется после получения метаданных от пиров. При запуске такой задачи по умолчанию скачиваются все файлы; затем их приоритеты можно изменить во вкладке «Файлы».

После завершения скачивания торрент продолжает раздаваться. Пауза или полный выход останавливают передачу. По умолчанию крестик сворачивает приложение в трей: для полного завершения выберите **«Выход»** в меню значка рядом с часами. Поведение крестика меняется в настройках.

**«Удалить из списка» сохраняет скачанные файлы.** Удаление установленного приложения также сохраняет загрузки и данные сеанса.

## Открытие двойным щелчком

Откройте **«Настройки» → «Зарегистрировать приложение»**, затем **«Приложения по умолчанию»**. В Windows выберите CurseTorrent для `.torrent` и, при необходимости, протокола `magnet`.

Регистрация добавляет обработчики для текущего пользователя. Окончательный выбор программы по умолчанию выполняется через Windows. Переносную копию сначала поместите в постоянную папку, а уже затем регистрируйте.

## Данные, обновление и удаление

Служебные данные находятся в `%LOCALAPPDATA%\CurseTorrent`: настройки, список торрентов, метаданные, fast-resume и диагностический журнал. Загрузки хранятся в выбранной папке; по умолчанию это `Downloads\CurseTorrent` в профиле пользователя.

Для обновления выйдите через трей, распакуйте новую сборку отдельно и запустите новый `install.cmd`. Для переносной версии заменяйте программные файлы только после выхода. Сеанс хранится отдельно от программы.

Установленную версию можно удалить через «Установленные приложения» Windows или `uninstall.cmd`. Удаляются только файлы из установочного списка. Загрузки, посторонние файлы и `%LOCALAPPDATA%\CurseTorrent` сохраняются.

## Сборка из исходников

Нужны Git и **.NET 10 SDK**. На Windows из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

Результат: `artifacts\CurseTorrent-win-x64.zip` и `SHA256SUMS.txt`. Скрипт сначала выполняет проверки, затем публикует автономную сборку `win-x64`.

Проверки ядра отдельно, в том числе на Linux:

```shell
dotnet restore tests/CurseTorrent.Tests/CurseTorrent.Tests.csproj --locked-mode
dotnet run --project tests/CurseTorrent.Tests/CurseTorrent.Tests.csproj --configuration Release --no-restore
```

Решение для IDE — `CurseTorrent.slnx`. Версии NuGet-зависимостей зафиксированы в `packages.lock.json`. Сборка сохраняет лицензии фактически включённых версий .NET. Workflow не использует квоту GitHub Actions Artifacts: готовые файлы размещаются в GitHub Releases.
