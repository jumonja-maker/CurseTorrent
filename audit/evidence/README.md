Среда Windows: .NET 10.0.15, OS build 26100, Windows PowerShell 5.1 для установщика, WPF при 96 DPI, рабочая область 1024×720. Среда Linux: .NET SDK 10.0.404. Исходники приложения идентичны исходному коммиту во всех прогонах. Тестовые состояния и файлы создавались отдельно от пользовательских данных.

Скриншоты — WPF-render в диагностической графической сессии. Они не включают нативную рамку Windows; внешние прозрачные участки не относятся к теме приложения. Первая серия снимков диалогов имела ошибку захвата Margin; в этой папке находятся только исправленные изображения. Успешное завершение диагностического процесса может фиксировать неправильное поведение, поэтому интерпретировать его следует вместе с отчетом.
