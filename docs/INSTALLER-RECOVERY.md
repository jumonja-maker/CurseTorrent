# Установка обновление и восстановление

Запускайте `install.cmd` из полностью распакованного текущего выпуска. Перед обновлением завершите CurseTorrent через меню значка в трее. Приложение устанавливается для текущего пользователя; права администратора не требуются.

## Как сохраняются файлы

Установщик сначала проверяет файлы пакета, затем готовит изменяемые программные файлы и резервные копии в отдельной временной папке рядом с папкой установки. Файлы программы меняются только после подготовки. При обычной ошибке копирования или замены устанавливаемые изменения откатываются. Сведения о незавершенной операции сохраняются в журнале; следующий запуск установщика восстанавливает прежнее состояние, прежде чем продолжить.

Пакет должен помещаться на диске вместе с временными копиями изменяемых файлов. При нехватке места до фиксации старая программа остается на месте. Проверка не является обещанием устойчивости к любой аппаратной ошибке: если диск перестал отвечать или резервная копия повреждена, установщик сообщает об этом и сохраняет доступные данные восстановления.

Новый установочный список содержит SHA-256 каждого программного файла. При обновлении неизвестный файл, совпавший по имени с файлом нового пакета, не заменяется. Измененный пользователем программный файл тоже не заменяется автоматически. Сообщение указывает его путь: перенесите нужную копию в отдельную папку и повторите установку. Проверенные неизмененные файлы старой версии, которых больше нет в пакете, удаляются; измененные сохраняются.

При удалении программы хеши проверяются снова. Измененные и неизвестные файлы остаются на диске, даже если лежат в папке приложения. Папка загрузок и `%LOCALAPPDATA%\CurseTorrent` не очищаются установщиком. Локальный manifest служит учетом установленных файлов, а не цифровой подписью пакета.

## Обновление ранней preview

Старый manifest версии 1 не содержит хешей. Установщик поддерживает переход на версию 2, сохраняя прежние перезаписываемые файлы в отдельной папке `CurseTorrent-before-upgrade-…` рядом с папкой установки. Точный путь показан после установки и записан в новый manifest. Это позволяет сохранить также файл, который пользователь успел заменить в старой версии.

Эта резервная папка не удаляется при последующем удалении программы. Проверьте ее содержимое и удалите самостоятельно, когда сохраненные файлы больше не нужны. Старые файлы, которые не заменялись и которых нет в новом пакете, остаются на месте как неизвестные.

Новый uninstaller не удаляет файлы по старому списку без хешей. Если он обнаружил manifest версии 1, сначала обновите установку текущим пакетом. Это ограничение защищает файлы, чье происхождение нельзя проверить по старым данным.

## Если установка прервана

После освобождения занятого файла или устранения ошибки диска повторите `install.cmd` с той же папкой назначения. Для обычного отказа копирования или замены повторная попытка не требует ручного удаления папки программы.

Если появилось сообщение о незавершенном восстановлении, сохраните папку `.ct-…` по указанному в сообщении пути и файлы журнала. Установщик не перезаписывает файл, который изменился уже после прерывания операции: сначала перенесите нужные пользовательские данные в отдельную папку, затем повторите восстановление. При неудачной очистке временной папки ее путь показывается отдельно; это не означает, что успешно установленная программа повреждена.

Ярлык и регистрация Windows выполняются после успешной записи программных файлов. Если этот отдельный этап завершился ошибкой, программа остается установленной; повторный запуск установщика повторяет регистрацию. Автоматическое назначение приложения по умолчанию остается выбором Windows и пользователя.
