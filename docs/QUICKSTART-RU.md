# CurseTorrent — быстрый старт

## Первый запуск

Распакуйте **весь** `CurseTorrent-win-x64.zip` и запустите `CurseTorrent.exe`. Установка .NET отдельно не нужна. Рядом с `.exe` должны оставаться все файлы из архива.

Необязательная установка: запустите `install.cmd`. Программа появится в меню «Пуск». Стандартный каталог — `%LOCALAPPDATA%\Programs\CurseTorrent`. Для другого каталога запустите из PowerShell:

```powershell
.\install.ps1 -InstallDirectory 'D:\Programs\CurseTorrent'
```

Выберите отдельную пустую папку или каталог, который уже создан этим установщиком. Все изменения выполняются для текущего пользователя.

## Скачать торрент

1. Нажмите **«＋ Торрент»** или перетащите `.torrent` в окно.
2. Выберите папку для содержимого, например `D:\Downloads`.
3. Оставьте отмеченными нужные файлы.
4. Если нужно продолжить ранее скачанные сторонние файлы, включите **«Разрешить дозагрузку в существующие файлы»**. Без этого разрешения клиент читает готовые данные, но защищает чужие файлы от записи. Для новой загрузки оставьте флажок выключенным.
5. Добавьте торрент. Если автоматический старт отключён в окне добавления, выберите задачу и нажмите **▶**.

Для magnet-ссылки используйте кнопку **«Magnet»**. До получения метаданных название и размер могут быть неизвестны. Все файлы включены по умолчанию; список появится после подключения к пирам. Уберите ненужные файлы через приоритет **«Не скачивать»** во вкладке **«Файлы»**.

## Управление

- **Ⅱ** — остановить передачу и сохранить состояние.
- **▶** — продолжить.
- **↻** — проверить имеющиеся файлы по хешам. На больших файлах это занимает время.
- **Папка** — открыть каталог загрузки.
- **Удалить из списка** — убрать торрент, сохранив файлы на диске.

При следующем запуске имеющиеся данные сначала проверяются по хешам. После проверки активные задачи продолжаются, если это включено в настройках. Торренты на паузе остаются на паузе. Повторная проверка не обрезает и не переименовывает существующие файлы. Завершённый торрент раздаёт скачанные части другим пользователям; чтобы остановить раздачу, поставьте его на паузу или завершите программу.

## Скорость и фон

В **«Настройках»** ограничения задаются в **КиБ/с**. `0` означает отсутствие ограничения, `1024` — 1 МиБ/с, `5120` — 5 МиБ/с. Лимиты действуют на всё приложение. Скорость раздачи также зависит от доступных пиров и соединения.

По умолчанию крестик закрывает окно, но загрузки продолжаются. В трее рядом с часами двойной щелчок по CurseTorrent возвращает окно; меню **«Выход»** завершает приложение. Поведение крестика меняется настройкой **«При закрытии окна продолжать работу в трее»**.

## Открывать файлы из Проводника

Нажмите **«Настройки» → «Зарегистрировать приложение»**, затем **«Приложения по умолчанию»**. Выберите CurseTorrent для `.torrent` и `magnet` в Windows. Уже запущенное приложение принимает новый торрент в то же окно.

## Если загрузка не начинается

Проверьте, что задача запущена и хотя бы один файл выбран. У magnet-ссылок сначала должны загрузиться метаданные. Если доступных пиров нет, клиенту неоткуда получить данные. Для сравнения можно добавить официальную раздачу Linux-дистрибутива с его сайта.

Если Windows показывает запрос брандмауэра, разрешите подключение CurseTorrent для той сети, в которой хотите пользоваться приложением. Необязательный UPnP/NAT-PMP помогает принимать входящие соединения на совместимом роутере; сам клиент не изменяет правила брандмауэра.

При сообщении о защищённом существующем файле выберите другую папку либо удалите только задачу из списка и добавьте её в прежнюю папку с разрешением дозагрузки. Это может потребоваться после обновления с 0.1.0: у старых файлов ещё нет записей принадлежности новой версии. Файл, который больше ожидаемого, нужно перенести вручную — клиент не удаляет лишние байты.

При ошибке диска проверьте свободное место и доступ к папке. Текст ошибки отображается у задачи; журнал — `%LOCALAPPDATA%\CurseTorrent\diagnostics.log`.

## Обновить или удалить

Сначала выполните **«Выход»** через трей. Для обновления установленной версии распакуйте новый архив отдельно и запустите новый `install.cmd`. Если меняли каталог установки, снова передайте тот же путь через `-InstallDirectory`.

При сбое установки повторите запуск того же установщика: журнал операции позволяет восстановить предыдущие файлы. При обновлении старой установки создаётся папка `CurseTorrent-before-upgrade-...`; сохраняйте её до проверки новой версии.

Удаление: **«Установленные приложения»** Windows или `uninstall.cmd`. Загрузки, сеанс и изменённые пользователем файлы сохраняются. У переносной копии установочного списка нет: её программную папку удаляют вручную, предварительно убедившись, что там не лежат нужные скачанные файлы.
